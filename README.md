# timegap3
## 使い方

`timegap` は、同じ日に記録した時刻を1行ずつ読み、直前の時刻から何秒経過したかを出力します。Python 3とBashが使える環境で、リポジトリのフォルダに移動して実行します。

```bash
printf '12:00:00\n12:00:03\n12:00:10\n12:01:00\n' | ./timegap
```

出力は次の3行です。

```text
3
7
50
```

時刻を1行ずつ書いたファイルからも読み込めます。

```bash
./timegap < times.txt
```

## 入力条件

- 時刻は半角の `HH:MM:SS` 形式で入力します。時は `00`～`23`、分と秒は `00`～`59` です。
- 同じ時刻が続くと `0` を出力します。入力が空、または正しい時刻が1行だけなら、何も出力せずに終了します。
- 形式が違う場合、範囲外の場合、時刻が逆戻りした場合は、行番号と理由を標準エラー出力に表示します。日付をまたぐ入力も逆戻りとして扱います。
- 正常終了時の終了ステータスは `0`、入力や引数にエラーがある場合は `1` です。

## テスト方法

```bash
bash test_timegap.bash
```

すべてのテストに成功すると、最後に `OK` が表示されます。
